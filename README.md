# Sanzo Quiz – Mbo Sanzo

Application mobile Android de quiz développée avec Flet et Python.

## Fonctionnalités
- Quiz interactifs
- Plusieurs niveaux de jeu
- Chronomètre
- Effets sonores
- Apprentissage et divertissement

## Installation
Téléchargez le fichier APK disponible dans la section Versions de ce dépôt, puis installez-le sur votre téléphone Android.
